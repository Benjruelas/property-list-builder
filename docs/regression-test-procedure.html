KnockScout Manual Regression Test Procedure

How to use this checklist
  1. Open the app at http://localhost:3000 (or your deploy URL) in a separate window.
  2. Pick a role filter matching the account you are testing (solo, team admin, restricted member, or logged-out).
  3. Work through each section. Click the status button to cycle: Not run → Pass → Fail → Blocked.
  4. Add notes on failures. Progress saves automatically in this browser via localStorage.
  5. Use Export JSON to attach results to a bug report or share with the team.
  6. Some cases are tagged desktop or mobile — resize the viewport or use device emulation as noted.
